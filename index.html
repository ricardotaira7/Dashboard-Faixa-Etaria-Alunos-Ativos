Sobre os dados

Este dashboard apresenta o perfil etário dos alunos ativos da Uni LS com base nos registros do ano de 2026. A idade dos alunos é calculada automaticamente a partir da data de nascimento, considerando como data de referência 11/08/2026. Os campos exibidos são derivados exclusivamente da base fornecida — nenhum dado foi inventado. Nomes e CPF não são incluídos nesta publicação; apenas idade, unidade, curso e modalidade são utilizados para as análises agregadas. Cursos registrados em caixa-alta correspondem à modalidade semipresencial e são consolidados sob o mesmo nome do curso presencial — use o filtro Modalidade ou a opção Cursos: Por modalidade para separá-los.
